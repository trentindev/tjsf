# TJSF : Création d'un petit framework Javascript

## Tiny JavaScript Framework

Créer un mini-framework JavaScript est une **approche pédagogique très puissante** pour aider à comprendre les fondations des frameworks modernes comme React, Vue ou Angular. Cela permet d’aborder des concepts essentiels comme :

- Le DOM virtuel ou les manipulations DOM
- Les composants et le templating
- La réactivité (binding data <-> UI)
- Le routing simple
- La gestion d’état
